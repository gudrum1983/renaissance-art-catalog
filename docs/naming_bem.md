# Нейминг классов и компонентов

В проекте используется классическая нотация указания имен компонентов:

`block-name__elem-name_mod-name_mod-val`

## Базовые правила

1. Каждый Vue-компонент с разметкой считается блоком.
2. Корневой DOM-элемент компонента должен иметь класс с именем блока, даже если у блока пока нет
   собственных стилей.
3. Имена записываются латиницей в нижнем регистре.
4. Для разделения слов в именах используется дефис (-).
5. Имя блока задает пространство имен для его элементов и модификаторов.
6. Имя элемента отделяется от имени блока двумя подчеркиваниями (__).
7. Имя модификатора отделяется от имени блока или элемента одним подчеркиванием (_).
8. Значение модификатора отделяется от имени модификатора одним подчеркиванием (_).
9. Значение булевых модификаторов в имени не указывается.

## Формат имен

| Описание                                  | Нейминг                                | Пример нейминга             |
|:------------------------------------------|:---------------------------------------|:----------------------------|
| Блок                                      | block-name                             | button-base                 |
| Блок с модификатором (булево)             | block-name_mod-name                    | button-base_full-width      |
| Блок с модификатором (значение)           | block-name_mod-name_mod-val            | button-base_size_sm         |
| Блок + Элемент                            | block-name__elem-name_mod              | button-base__icon           |
| Блок + Элемент с модификатором (булево)   | block-name__elem-name_mod-name         | button-base__icon_is-active |
| Блок + Элемент с модификатором (значение) | block-name__elem-name_mod-name_mod-val | button-base__icon_size_sm   |
